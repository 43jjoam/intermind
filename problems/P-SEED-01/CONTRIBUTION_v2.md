## Body

A first visitor should land on one live Problem that already shows:

```text
Contribution
→ Challenge
→ Revision
→ unresolved remainder
```

That landing page is a demonstration, not a claim that every visitor's own Problem is unimportant. A visitor who arrives with a concrete Problem may ignore the seed; the seed exists so the protocol is visible, not so founder framing becomes the only legitimate question.

Search into mostly empty territory can make starting a new question the most obvious available action. Whether that visibility is an epistemic reward remains contested. Identifying a good Problem can itself be the scarce intellectual contribution. The event this protocol is trying to keep visible is still a specific objection that survives revision and remains inspectable by a later participant.

A two-mode entry — inspect a live cycle, or bring a Problem — may later avoid treating one path as the only door. This Stage-0 object still ships one default because the current experiment needs one inspectable cycle, not because a single default has been shown to be necessary.

Search can be added when there is enough territory for navigation to be a real problem.
